# AEGIS Intelligence

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://crisis-command-center-two.vercel.app/)

## Overview
**AEGIS Intelligence** is a next-generation intelligence interface designed to streamline complex operational data, telemetry, and multimodal interactions. Built with cutting-edge web technologies, it features a highly dynamic, tactical UI built for rapid response and deep data exploration.

## Key Features
- **Gemini AI Omnibox:** A unified command input powered by advanced AI to process natural language requests, commands, and queries instantly.
- **Spark Tactical Telemetry Matrix:** Real-time data visualization and telemetry tracking for situational awareness.
- **Collaborative Notebooks:** Seamlessly collaborate on operations, share insights, and compile intelligent reports in real-time.
- **Multimodal Creation:** Support for diverse data types, enabling the generation and manipulation of text, media, and structural data points in a single platform.

## Architecture & Tech Stack
This application leverages a modern web stack to deliver a fast and responsive experience:
- **Framework:** React / Vite (Lightning-fast HMR and optimized builds)
- **Styling:** CSS3 (incorporating dark mode and sleek tactical themes)
- **Typography:** JetBrains Mono, Inter, and Space Grotesk for a crisp, futuristic aesthetic.
- **Hosting:** Vercel

## Setup (Local Development)

If you have access to the source code, you can run the project locally:

1. **Clone the repository**
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   ```
4. **Build for production:**
   ```bash
   npm run build
   ```
